## Job Finder Application
Hello Everyone! Welcome to a personal project of mine!
 
I am going to be creating an application that allows me to find jobs on the internet. 

**Status:** In progress

## Goals

- [ ] Add, edit and delete jobs I'm interested in
- [ ] Track each job's status: Saved, Applied, Interview, Offer, Rejected
- [ ] Filter the list by status
- [ ] Search for jobs by type (stretch goal)

## Tech stack

- **Front end:** React
- **Back end:** PHP (REST API), HTML, CSS
- **Database:** MySQL
- **Tools:** Docker, Git

Because i love coding! And to also begin learning a new language which is very exciting :)
